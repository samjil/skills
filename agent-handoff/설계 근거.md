# agent-handoff 스킬 — 설계 근거

Claude ↔ Antigravity(agy) 파일 대화 채널 규약을 **독립 스킬 및 런타임 통합 구조**로 개편한 기록.
무엇을 왜 그렇게 정했는지, 무엇을 일부러 빼 두었는지만 적는다. 규약 본문은 `SKILL.md`에 있다.

| 항목 | 값 |
|---|---|
| 스킬 정본 | `samjil/skills` (`agent-handoff/`) — [skills.sh](https://skills.sh) 규약 준수 |
| 원클릭 설치 | `install.ps1` (Antigravity & Claude 전역 등록) |
| agy 연동 | `~/.gemini/config/skills.json` 에 스킬 저장소 경로 등록 |
| Claude 연동 | `~/.claude/skills/agent-handoff` 독립 폴더 직접 복사/배치 |
| 대화 기록 | `~/.samjil/agent-handoff/<프로젝트명>/` — **PC마다 독립 전역 폴더.** |
| 웹 뷰어 연동 | `http://127.0.0.1:8787` (`viewer/serve-handoff.bat`) 전용 뷰어 내장 |
| 처음 적용 | 실전 웹 프론트엔드 프로젝트 (메시지 70+건 실전 운용 검증 완료) |
| 개편 일자 | 2026-09-17 (samjil/skills 독립 저장소 분리, skills.sh 호환, 독립 웹 뷰어 내장) |

## 1. 왜 독립 스킬 저장소(`samjil/skills`)로 분리했나

기존에는 로컬 클라우드 동기화 드라이브 등에 원본을 두고, 각 PC마다 `skills.json`에 경로를 수동으로 타이핑하거나 정션을 걸어야 했다.
이로 인해:
1. 새 PC에서 작업할 때마다 경로를 기억하고 수동 설정해야 하는 번거로움이 있었다.
2. 스킬 규약 자체가 Git으로 버전 관리되지 않고 로컬 드라이브에만 의존했다.
3. [skills.sh](https://skills.sh) 오픈소스 에이전트 스킬 생태계와 연동하여 `npx skills add` 또는 원클릭 스크립트로 누구나 쉽게 설치할 수 있도록 독립 Git 저장소로 구축했다.

## 2. 왜 대화 기록을 `~/.samjil/agent-handoff` 로 배치했나

특정 프로젝트 저장소나 외부 브리지 도구에 종속되지 않고 영구히 자립하기 위해 사용자 홈 디렉터리의 통합 루트(`~/.samjil/agent-handoff/`)로 표준화했다:

1. **완전한 독립성 및 단일 통합 관리**:
   특정 Git 저장소의 위치가 바뀌거나 폐지되어도 대화 기록은 사용자 PC의 표준 경로(`~/.samjil/agent-handoff/<프로젝트명>/`)에 영구 보존되며, 홈 디렉터리에 여러 점(dot) 폴더가 난립하지 않고 `~/.samjil/` 아래에 스킬명과 1:1로 깔끔하게 통합된다.
2. **Git 격리 보장**:
   프로젝트 코드 저장소 바깥에 존재하므로, 대화가 수천 건 불어나도 프로젝트의 `.gitignore`를 건드리거나 코드 커밋에 실수로 섞일 위험이 0%다.
3. **다중 PC 충돌 원천 차단**:
   PC마다 각자의 홈 디렉터리 경로를 사용하므로, 다른 PC에서 작업하더라도 메시지 번호(`0001`, `0002`...)가 충돌하거나 원장이 덮어써지지 않는다.

## 3. 원클릭 설치 스크립트 (`install.ps1`) 의 도입

### 목적
새 PC, 새 프로젝트, 새 세션에서 사용자가 프롬프트에 스킬 경로나 지시문을 입력할 필요 없이,
저장소 루트에서 **`.\install.ps1` 한 번 실행만으로 전역 스킬이 영구 활성화**되도록 한다.

### 스크립트가 하는 일
1. `~/.gemini/config/skills.json`의 `entries`에 현재 저장소 경로를 안전하게 등록한다.
   - Antigravity는 이 한 줄로 저장소 안의 `agent-handoff`, `agent-delegate-agy` 등을 전역 스킬로 즉시 자동 탐색한다.
2. `~/.claude/skills/`에 저장소 내 모든 스킬 폴더를 직접 복사/배치하여 Claude Code에서도 정션 없이 전역 사용 가능하게 한다.
3. 원격 실행(`irm ... | iex`) 시 GitHub에서 최신 코드를 받아 전역 배치한다.

## 4. 내장 독립 웹 뷰어 (`agent-handoff/viewer/`)

- 스킬 내부에 독립 HTTP 서버(`serve-handoff.ps1`)와 대시보드 UI를 내장하여 브릿지 도구 없이 단독 실행 지원.
- `viewer/serve-handoff.bat` 실행 시 `http://127.0.0.1:8787`에서:
  - 프로젝트별 원장(`INDEX.md`) 목록을 타임라인 카드로 표시
  - 상태 배지(`보냄`, `읽음`, `처리됨`, `확인함`, `보류`) 시각화
  - 카드 클릭 시 메시지 마크다운 본문(`msg/00XX-*.md`)을 인라인 렌더링
  - `BRIEF.md` 프로젝트 맥락을 접이식 카드로 상시 열람 가능하게 지원.
