# sub-agent — agy · opencode 통합 서브 에이전트

Claude 가 큰 파일·로그를 직접 읽지 않고 **파일 경로 + 질문**만 넘기면, 스크립트가 디스크에서 파일(과 줄 범위)을 읽어 서브 에이전트(agy 또는 opencode)에게 주고 **핵심 결론만** 돌려줍니다. 읽기 전용입니다.

```
python sub-agent.py -f "src/OrderService.java:100-250" -f logs/error.log -q "트랜잭션 롤백 안 되는 원인"
python sub-agent.py --engine opencode -f app.py -q "버그 추적"
python sub-agent.py --check
```

표준 출력은 답변만이고, 쓴 엔진과 폴백 이유는 표준 오류에 한 줄로 나옵니다. 종료 코드: 0 성공 / 1 모든 엔진 실패 / 2 사용법·입력 오류. 표준 라이브러리만 쓰므로 Python 3.8+ 만 있으면 됩니다.

## 라우팅과 폴백

| 상황 | 먼저 쓰는 엔진 |
|---|---|
| 파일이 없음 · 디렉터리 탐색 · 주입 크기 200KB 초과 | `agy` |
| 코드 파일 3개 이하, 크기 작음 | `opencode` |
| `--engine agy\|opencode` | 지정한 엔진 |

먼저 쓴 엔진이 실패(429·쿼터·타임아웃·미설치·빈 응답·오류)하면 **다른 엔진으로 자동 전환**합니다. agy 는 쿼터 오류일 때 같은 엔진의 다음 모델(`SUB_AGENT_AGY_MODELS`)을 먼저 시도합니다. 전환을 끄려면 `--no-fallback`.

## 파일 주입

- `-f 경로` 전체 · `-f 경로:100-250` · `-f 경로:100-` · `-f 경로:-50` · `-f 경로:75`. 여러 번 쓸 수 있습니다.
- 줄마다 `0100|내용` 접두어를 붙여, 답변이 실제 줄 번호를 인용하게 합니다.
- 파일 하나당 400KB(`--max-file-bytes`)가 넘으면 로그(`.log/.txt/.out`)는 **끝**, 나머지는 **앞**만 넣고 알립니다.
- 디렉터리를 주면 본문은 넣지 않고 agy 에 `--add-dir` 로 열어 줍니다.
- 지시·질문·파일 본문은 임시 파일(`request.md`) 하나에 담아 엔진에 넘기고 끝나면 지웁니다. 명령줄에는 ASCII 고정 문장만 실어 Windows 의 길이 제한과 `.cmd` 따옴표 문제를 피합니다.

## 출력 압축

고정 시스템 규칙: 인사말·서론·부연 금지 / 첫 줄 `결론:` + `- 파일:줄 사실` 근거 / 수정은 바뀔 줄만 / 모르면 `확인 불가` / 읽기 전용 / 40줄 이내. 그래도 남는 인사말 첫 줄은 걷어 내고, 6000자(`--max-chars`)를 넘으면 자릅니다.

## 설치와 인증

1. **Python 3.8+**: `python --version` (Windows 는 `py -3 --version`).
2. **agy**: 이미 연동돼 있으면 그대로. `agy models` 로 모델 이름을 확인합니다.
3. **opencode**: 공식 npm 패키지 이름은 `opencode-ai` 입니다(`@opencode/cli` 가 아님).
   ```
   npm install -g opencode-ai
   opencode auth login          # 공급자 목록에서 OpenRouter 선택 후 API 키 입력
   opencode auth list           # 저장됐는지 확인
   opencode models openrouter   # 쓸 수 있는 모델 이름 확인 — 무료 모델은 자주 바뀐다
   ```
4. `.env.example` 을 `.env` 로 복사해 모델 이름 등을 고칩니다(스크립트 옆, `~/.sub-agent/.env`, 현재 폴더 순으로 읽음).
5. `python sub-agent.py --check` 로 설치·인증 상태를 봅니다.

```markdown
## 서브 에이전트 위임 규칙 (sub-agent)

무거운 읽기·분석은 직접 하지 말고 `sub-agent` 로 넘겨 토큰을 아낀다. 파일 내용을 내가 읽어서 프롬프트에 붙여 넣지 않는다 — 경로만 넘긴다.

호출: `python <경로>/sub-agent.py -f "<파일>[:시작-끝]" [-f ...] -q "<질문>"`

위임한다:
- 200줄이 넘는 파일·로그·덤프를 읽어야 하는 분석(원인 추적, 요약, 패턴 찾기)
- 여러 파일에 걸친 조사, 폴더 탐색("어디에 X 가 있나")
- 특정 파일의 버그 탐지·리팩토링 검토 초안(단일/소수 파일은 `--engine opencode`)

직접 한다:
- 50줄 안팎의 작은 읽기, 이미 알고 있는 파일 한 군데 수정
- 파일을 고치거나 만드는 일(서브 에이전트는 읽기 전용)
- 보안·결제·데이터 삭제처럼 틀리면 곤란한 판단 — 서브 에이전트의 답은 근거(파일:줄)를 직접 확인한 뒤에 쓴다

쓰는 법:
- 질문은 한 가지를 구체적으로(무엇을 / 어디서 / 어떤 형식으로). 줄 범위를 알면 `:100-250` 으로 좁힌다.
- 답은 "결론 + 파일:줄 근거"로 온다. 근거가 이상하면 그 줄만 직접 열어 확인한다.
- 종료 코드 1(모든 엔진 실패)이면 한 번만 다시 하고, 그래도 안 되면 직접 하거나 사용자에게 알린다.
- 같은 질문을 엔진만 바꿔 되풀이하지 않는다(폴백은 스크립트가 한다).
- 기존 `samjil-delegate-agy` 스킬(오래 걸리는 작업·파일 수정 위임)과 겹치지 않는다: 읽기·분석은 sub-agent, 쓰기·장시간 작업은 delegate-agy.
```

## 실제 CLI 로 확인한 것 / 아직 못 한 것

- 확인함: opencode 의 `--file` 은 값을 여러 개 받는 옵션이라 뒤에 오는 메시지를 파일로 삼킨다(`File not found`) -> 메시지를 맨 앞, `--file` 을 맨 끝에 둔다.
- 확인함: agy 는 헤드리스에서 도구 권한(`command`)을 물을 수 없어 자동 거부한다 -> 파일을 읽게 시키지 않고 `-p @요청파일` 로 내용을 프롬프트에 직접 넣는다. **디렉터리 탐색(`-f 폴더`)은 agy 가 명령을 써야 해서 같은 거부가 날 수 있다**(그때는 `SUB_AGENT_AGY_SKIP_PERMISSIONS=1`).
- 아직 못 함: `opencode run` 의 기본 출력이 답변 텍스트만인지(도구 호출 로그가 섞이는지), 고른 무료 모델이 실제로 형식을 지키는지.

시험(`tests/sub-agent/sub-agent.tests.py`, 34개)은 가짜 agy·opencode 로 돌립니다.
